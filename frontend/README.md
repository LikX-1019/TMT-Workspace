# TMT Workspace Frontend

Vue 3, TypeScript, Vite, Pinia, Vue Router, and Element Plus foundation for the TMT Workspace console.

```bash
npm install
cp .env.example .env
npm run dev
npm run build
```

The development server proxies `/api` to `http://127.0.0.1:8000`. Dynamic workspace routes, login, RBAC-aware navigation, and system modules will be implemented after the backend contracts in their planned phases.
